Huawei SUN2000 Modbus Register Map

How to read a Huawei SUN2000 inverter directly over Modbus TCP or RS485 — through the SDongle, the inverter's own network port, or the RS485 terminals. Connection settings, the registers that matter for monitoring, their gains and data types, the power meter and battery registers, and the mistakes that make a SUN2000 return exceptions or nonsense. Behind a SmartLogger the registers are remapped — for that case see the SmartLogger guide. Other inverters: Sungrow.

Connection Settings

A SUN2000 can be reached three ways, and they do not use the same port or unit ID. Most "no response" problems are one of these two numbers.

PathProtocol / portUnit IDNotes
SDongleA-05 (WLAN-FE dongle)Modbus TCP, 5021–247 = the inverter's RS485 address (usually 1); 100 = the dongleModbus TCP must be enabled first (below). One client at a time.
Inverter's built-in WLAN / FE portModbus TCP, 502 or 66070 (default for the directly connected device)Huawei's documents differ on the port by issue and firmware — try 502, then 6607.
RS485 terminalsModbus RTUthe inverter's RS485 addressCommonly 9600 baud, 8N1, address 1 — settable on the inverter. Huawei's Modbus document does not state the defaults; check the inverter's settings.
Behind a SmartLoggerModbus TCP / RTU0Different, remapped register map — see the SmartLogger guide.
Unit ID 0 vs 1: Huawei's interface definition says unit ID 0 addresses the directly connected device by default. Many SUN2000s also answer on 1. Through an SDongle, use the inverter's RS485 address — 100 reaches the dongle's own registers, not the inverter. If one ID times out, try the other before suspecting the wiring.

Enabling Modbus TCP on the SDongle

Out of the box the SDongleA-05 does not accept Modbus TCP. Huawei's SDongleA-05 Modbus TCP Guide describes the switch:

1 In the FusionSolar app (formerly SUN2000 app), connect to the inverter and log in as installer.

2 Open Settings › Communication configuration › Dongle parameter settings › Modbus-TCP.

3 Choose Enable (Unrestricted) to allow any client on the LAN, or Enable (Restricted) to allow a single trusted IP address.

One client at a time. Even in Unrestricted mode the dongle serves only one Modbus TCP client at a time. If a home-automation system, an EMS or a second logger is already polling, your connection is refused or dropped — stop the other poller first. The guide also lists minimum firmware for the option to appear (e.g. SDongleA-05 V100R001C00SPC124, SUN2000MA V100R001C00SPC139); update the dongle and inverter if the menu item is missing.

Addressing, Data Types and Gains

  • Function code 03 for everything. All SUN2000 registers — including the 3xxxx ones — are holding registers read with FC03. There is no FC04. Writes use FC06 or FC16.
  • Addresses are sent as written. The numbers in Huawei's tables are protocol addresses: register 32080 goes on the wire as 32080. In a tool that uses 1-based "4xxxx" numbering, enter one more.
  • 32-bit values span two registers, high word first. Read both in one request and combine them before scaling.
  • Gain means divide. A gain of 1000 on a kW value: raw 7717 is 7.717 kW.
  • Read only the blocks Huawei defines. A request that runs into an undefined address is refused with exception 0x02 (illegal data address) — the whole request, not just the missing register. Up to 125 registers per request.

Huawei lists 40125 as U16 in one issue of the document and I16 in another — the valid range (0–100 %) is the same either way.

Common Mistakes

  • Timeouts: wrong unit ID (0 vs 1 vs the RS485 address behind a dongle) or wrong port (502 vs 6607), or Modbus TCP not enabled on the dongle.
  • Connection refused after it worked once: another client is connected — the dongle serves one at a time.
  • Exception 02 on a read that "should" work: the request crosses an undefined address. Split it into the defined blocks — e.g. 32016–32019, 32064–32095, 32106–32117, 37100–37137.
  • Active power reads 0 or a huge number: only one of the two registers was read, or the 32-bit pair was combined low word first.
  • Off by one: 1-based tools need the Huawei address + 1.
  • Phase B/C read nonsense: it is a single-phase inverter.
  • Polling too hard: the dongle times out after about 5 seconds without a reply; leave room between requests, a 1–2 s poll is plenty for monitoring.

Frequently Asked Questions

Which port does the SUN2000 use for Modbus TCP?

Through the SDongleA-05 it is port 502. On the inverter's built-in WLAN/FE port Huawei's documents give 502 in one issue and 6607 in another, depending on firmware; if 502 does not answer, try 6607.

What unit ID should I use?

For a direct connection, 0 (Huawei's default for the directly connected device) — many inverters also answer on 1. Through an SDongle, use the inverter's RS485 address, usually 1; ID 100 is the dongle itself.

Why do I get exception 02 (illegal data address)?

The request covers an address Huawei does not define, and the SUN2000 refuses the whole request. Read the defined blocks separately, e.g. 32064–32095 for the AC values and 32106–32117 for the energy counters.

Can two programs read the inverter at the same time?

Not through the SDongle: it serves one Modbus TCP client at a time, even in Unrestricted mode. Let one program poll and share the values — ModbusManager's gateway can republish them as a Modbus map for other systems.

Is this the same register map as through a SmartLogger?

No. A SmartLogger remaps each inverter into its own address block (51000 + 25 × (N − 1)) on unit 0. Use this page for a direct connection and the SmartLogger guide behind a logger.
