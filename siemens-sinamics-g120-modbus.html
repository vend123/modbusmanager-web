Siemens SINAMICS G120 Modbus RTU: Register Map, STW1 and ZSW1

A SINAMICS G120 with a CU240B-2 or CU240E-2 control unit is a Modbus RTU slave once you choose it in p2030 — and Siemens gives it a fixed register map: control and status words at 40100 and 40110, speed, frequency, current and power from 40340, fault numbers from 40400. This page covers which control units have Modbus at all, the setup parameters, the map with its scaling, and the STW1 / ZSW1 bits, from Siemens's operating instructions and fieldbus function manual.

Only the RS-485 variants ending in -1BA1 speak Modbus RTU. A DP or PN control unit cannot be switched to Modbus by any parameter — check the article number before planning the wiring.

The address switch on the control unit wins over p2021. A new address or protocol applies after the power is switched off and on. If no process data arrive within p2040 the drive faults; the timeout counts only the process-data registers (40100, 40101, 40110, 40111).

Register Map

FC03 reads, FC06 / FC16 write. On the wire the address is the register minus 40001: Siemens's own example reads 40110 with start address 006D hex = 109. A register outside the map is answered with an exception.

STW1 and ZSW1

STW1 (40100): bit 0 ON / OFF1, 1 no OFF2 (coast), 2 no OFF3 (quick stop), 3 enable operation, 4–6 ramp generator and setpoint enable, 7 acknowledge fault on 0→1, 10 control via PLC (0 = the drive ignores the Modbus process data), 11 reverse, 13 / 14 motorized potentiometer up / down. Bits 1–6 and 10 set with bit 0 = 0 gives 0x047E (ready); setting bit 0 gives 0x047F and the motor runs to the setpoint in 40101.

Switching on inhibited (bit 6) after a power-up means the drive needs an OFF1 first: write 0x047E, then 0x047F.

Common Mistakes

  • No answer at all: a DP or PN control unit, or p2030 not 2, or no power cycle since.
  • Answers on the wrong address: the address switch is not 0, so p2021 is ignored.
  • Everything one register off: 40110 requested as 110; on the wire it is 109.
  • Commands ignored: STW1 bit 10 (control via PLC) is 0, or the drive is in manual (40349 = 0).
  • Drive faults after 10 s: p2040 monitoring; poll the process data registers continuously.
  • Frequency 3970 instead of 39.7: 40342 is Hz × 100.

  1. Check the control unit is a -1BA1 type; set the address switch to 0.

Frequently Asked Questions

Which SINAMICS G120 control units support Modbus RTU?

The RS-485 variants: CU240B-2 (6SL3244-0BB00-1BA1), CU240E-2 (6SL3244-0BB12-1BA1) and CU240E-2 F (6SL3244-0BB13-1BA1). The DP and PN variants do not.

What are the G120 Modbus registers for control and status word?

40100 is control word STW1 and 40101 the main setpoint; 40110 is status word ZSW1 and 40111 the main actual value. On the wire subtract 40001: ZSW1 is address 109.

How do I set the Modbus address on a G120?

Set p2030 = 2 (Modbus RTU) and p2021 to the address, with the control unit's address switch at 0 — otherwise the switch wins. Power the drive off and on.

How is the G120 setpoint scaled on Modbus?

40101 and 40111 use 4000 hex (16384) = 100 % of the reference speed p2000, which you can read at 40324. Speed in rpm is also at 40341 directly.

Why does the G120 ignore my Modbus commands?

STW1 bit 10 (control via PLC) must be 1, the drive must not be in manual (40349), and after power-up an OFF1 is needed first: 0x047E, then 0x047F.
