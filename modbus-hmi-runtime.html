// what runtime is

Pro to design, Runtime to deploy

A machine builder ships the same machine many times. The engineer who designs the HMI needs the full editor; the hundred machines in the field only need to show that one dashboard and keep it running. Paying for a full design licence on every one of them makes no sense.

ModbusManager Runtime splits the two. You build the dashboard in ModbusManager Pro as usual, then press 📦 to export a runtime package — the dashboard, a service PIN and a start-with-Windows choice in one .mmrt file. Installed on a panel PC, it turns that PC into a kiosk for your machine.

The package carries no connection settings. Each machine keeps its own COM port or IP address, asked once on the first start, so one package fits every machine of the series.

In one sentence

Runtime is a $39 per-machine licence that runs a dashboard package made in ModbusManager Pro full screen and locked down, with a PIN-protected way back in for service.

// from design to the field

Four steps to a runtime machine

Step 1
Design in Pro
Build the dashboard against a real or simulated device: gauges, tanks, pumps, trends, alarms, buttons. Any Pro licence or the free trial will do.
Step 2
Export the package
On the dashboard toolbar press 📦, name the machine or line, set a 4–8 digit service PIN and choose whether it starts with Windows. You get one .mmrt file.
Step 3
Install on each PC
Install ModbusManager Pro on the panel PC, open 📦 and choose the package. The PC restarts into the kiosk and asks once for its connection: COM port or IP address.
Step 4
Activate
Each PC shows its Machine ID. Send us the IDs, and every machine gets its own Runtime key. Until then it runs on the 14-day trial, and after that in 2-hour demo sessions.

// the way back in

Service with a PIN

Only someone with the package’s PIN gets past the dashboard.

To open serviceHow
With a keyboardCtrl+Shift+F12. On many laptops and compact keyboards F12 is a media key: press Fn+Ctrl+Shift+F12.
Without a keyboardHold a finger or the mouse on the top-right corner of the screen for 5 seconds. A spinner appears after one second; letting go earlier does nothing.
Wrong PINFive wrong PINs in a row lock service for a minute.

Behind the PIN: change the connection, install another package (to update the dashboard on a machine), see the licence, make the PC an ordinary one again, or close the application. On a PC with a Pro licence there is also Open the editor — with a way back to Runtime — so you can fix a dashboard on site and put it straight into a new package.

Locking Windows itself. No application can block the Windows key or Ctrl+Alt+Del. For a panel the operator must not leave at all, use Windows’ own kiosk features — Assigned Access, or Shell Launcher on Enterprise and IoT editions — with ModbusManager as the application it starts.

// frequently asked questions

ModbusManager Runtime — FAQ

Is Runtime a separate program?+
No. Every machine gets the normal ModbusManager Pro installer. What makes a PC a runtime machine is the package installed on it; the Runtime key only licenses that use.
Do I need Pro to make a package?+
Yes — the dashboard editor and the 📦 export are Pro features. One Pro licence (or the free trial while you evaluate) is enough for any number of packages.
What happens without a licence?+
For the first 14 days the PC runs on the trial. After that the package runs for 2 hours at a time, then stops polling and shows the Machine ID with an Activate button; a restart gives another 2 hours. You can commission and test before ordering.
How do I get out of the kiosk?+
Ctrl+Shift+F12 (Fn+Ctrl+Shift+F12 on many laptops), or hold the top-right corner of the screen for 5 seconds, then enter the package’s service PIN.
What if the panel PC has a different screen resolution?+
By default the package fits the dashboard to the machine’s screen: it is scaled as a whole, keeping its proportions, and centred, so the same package works on 1024×768, 1280×800 and 1920×1080 panels and with Windows display scaling. If you prefer exact pixels, choose “Actual size (1:1)” when you export.
How do I update the dashboard on machines already in the field?+
Export a new package in Pro and install it through the service menu on each machine. Replacing a package needs that machine’s current service PIN.
Does the package contain the connection settings?+
No. Each machine is asked for its own connection on the first start and keeps it; it can be changed later in the service menu. That is what lets one package serve every machine of a series.
Can a Runtime machine later become a full Pro?+
Yes. Activate a Pro key on it in the licence window; the PC then opens as an ordinary ModbusManager Pro once the package is removed.
How is Runtime licensed and bought?+
$39 one-time per machine, bound to that PC’s Machine ID. Order by e-mail at license@modbusmanager.com with the Machine IDs; you pay an invoice and receive one key per machine.
