How every map is checked

  • Address convention. 30001, 40001, 400001, 1-based or the wire address itself: decided from the manual's own examples, written in the report.
  • Every row against the document: data type, word order (MSW or LSW first), scale and unit.
  • The device's traps: registers that must be read alone, the largest request the device accepts, values that exist only on some models or firmware.
  • Read back in ModbusManager Pro. The workspace is loaded against a simulator of your device, 32-bit values above 65535 and signed values below zero, and every tag must read back exactly.

Questions

Which devices can you do?+
Any Modbus RTU or Modbus TCP device whose manual or register list has the registers: energy meters, power analysers, drives, inverters, battery systems, HVAC controllers, gateways. One order is one device model. If a manual covers a whole series, say which model you have.
What do you need from me?+
The vendor document with the register table (PDF, XLS, XLSX, CSV or TXT, up to 3 files, 25 MB together) and the exact model. If you already know the interface (RTU or TCP) or the values you care about most, write them in the notes.
What if the document has no register map?+
Then we tell you within 48 hours. We do not invent registers that the document does not define.
Do I need ModbusManager Pro?+
The workspace opens in ModbusManager Pro (the 14-day trial works). The report and the CSV are for any tool: a PLC, a SCADA system, Home Assistant or a spreadsheet.
How do you check the map?+
Every row is checked against the document: address convention (30001, 40001, 1-based or wire address), data type, word order and scale. The workspace is then loaded in ModbusManager Pro against a simulator of your device, and every tag must read back the value we put in. The traps we find (a register that must be read alone, the largest request, values that exist only on newer firmware) are written in the report.
What happens to my document?+
It is used only for your order, stored in our Google Drive and deleted 90 days after delivery, or earlier if you ask (support@modbusmanager.com).
