Eastron SDM230 and SDM72 Modbus Registers: One Line, Two Meters

The Eastron SDM230-Modbus (single-phase, 100 A direct) and the SDM72 (three-phase, 100 A direct) are the meters most often found next to a heat pump, a wallbox or a PV inverter. Both use Eastron's familiar input-register map — but the SDM72 exists in versions with very different register sets, Eastron's current manuals contain no register list at all, and the meters refuse requests with an odd number of registers. This page covers what Eastron's own documents say, and how to read both meters on one RS-485 line.

Both meters ship as address 1. Two meters on one line will not answer until one of them is renumbered — on the display, or by writing holding register 40021 (FC16, Float32). The older protocol documents list baud codes only up to 9600 in register 40029 (0 = 2400, 1 = 4800, 2 = 9600, 5 = 1200); the current meters offer 19200 and 38400 on the display.

Three Rules for Every Eastron Meter

1. Input registers, address minus 30001

Measurements are input registers, read with FC04. Eastron writes them as 30001, 30007… and also gives the hex start address: 30001 is 00 00, 30007 is 00 06. On the wire the address is the number minus 30001. Settings are holding registers: FC03 to read, FC16 to write.

2. Always an even number of registers

Every value is a Float32 in two registers, and Eastron's protocol says read and write requests must ask an even number of registers — an odd count is answered with an exception. (A single-register read gets an "instrument type specific value" for old SCADA systems, which is not a measurement.) Ask for 2, 4, 40… never 1, 3 or 41.

3. At most 30 values per request

The SDM230 protocol limits one request to 30 values — 60 registers; more is an exception. (Another section of the same document says 40 parameters; stay at 60 registers and it works either way.) Reading 30001–30080 needs two requests.

Test it: read 30001 (wire 0, FC04, quantity 2). A V2 answers with the phase-1 voltage, around 230. The original SDM72D-M documents nothing there — if you see 0 or an exception, you have the nine-register meter, and only power and energy are available. Plan the panel before you buy: an SDM72D-M cannot give you per-phase currents, whatever the master asks.

Changing Settings over Modbus

Holding registers, one parameter (two registers, Float32) per FC16 message: 40019 parity and stop bits (0 = none / 1 stop, 1 = even, 2 = odd, 3 = none / 2 stop), 40021 address, 40029 baud rate. On the SDM72 the protected settings need the password first, written to 40025 (default 1000). The resettable energy is cleared by writing 0003 to 461457 on the SDM72. A new address or baud rate applies to the next request — change the master straight after.

Common Mistakes

  • Exception on a request that looks right: an odd register count (1, 3, 41) or more than 60 registers.
  • Nothing answers on a two-meter line: both are still address 1.
  • Voltage reads 0 on an SDM72: it is an SDM72D-M with nine registers, not a V2.
  • Power 1000 times too big: it is W, not kW.
  • Total energy grows while exporting: 30343 is import + export; use 30073 / 30075, or 30397 net on the V2.
  • FC03 reads nonsense: measurements are input registers, FC04.

Step-by-Step: Two Meters on One Line with ModbusManager

  1. Give the second meter address 2 on its display (or write 2.0 to 40021 while it is alone on the line).
  2. Wire A to A and B to B, terminate both ends of the line.
  3. In ModbusManager choose RTU, 9600 baud, no parity, 1 stop bit (the defaults).

Frequently Asked Questions

What are the Modbus registers of the Eastron SDM230?

Input registers read with FC04, Float32: 30001 voltage, 30007 current, 30013 active power in W, 30031 power factor, 30071 frequency, 30073 import kWh and 30075 export kWh. On the wire the address is the register minus 30001, so voltage is address 0.

Why does my Eastron meter return an exception?

Eastron meters require an even number of registers in every request, because each value is a Float32 in two registers, and at most 60 registers (30 values). A request for 1, 3 or 61 registers is refused.

Why does my SDM72 not show voltage or current?

The original SDM72D-M documents only nine registers: total power, import, export and total energy, resettable energies and import / export power. Voltages and currents per phase need the SDM72DM-V2. Read 30001 to tell them apart.

Can an SDM230 and an SDM72 share one RS-485 line?

Yes, with different addresses: both ship as address 1, so change one on its display or by writing register 40021 with FC16 while it is alone on the line. Same baud rate and parity on both.

What is the SDM72 password for Modbus settings?

The protected holding registers need the password written to 40025 first; Eastron's protocol gives 1000 as the default.
