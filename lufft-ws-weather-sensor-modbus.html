Lufft WS Weather Sensor Modbus: Switch from UMB, Reg. No. vs Reg. Addr., 65535 = Not Fitted

Lufft's WS smart weather sensors — WS200-UMB to WS600-UMB, now sold by OTT HydroMet — measure wind, temperature, humidity, pressure, radiation and precipitation in one head, and are common on PV plants and roads. They can speak Modbus RTU, but they ship speaking Lufft's own UMB protocol, their register table has two number columns, and a sensor your model does not have reads 65535. This guide covers all three.

About the source. The register table on this page is from Lufft's operating manual for the WS family, document version V26 (10/2014). Newer manuals (from 2024) move the Modbus chapter into a separate “User Manual Smart Weather Sensors”, and newer firmware may add channels. The addresses below have been stable in the copies we have seen, but check them against your sensor's manual.

Switch the Sensor to Modbus

  • Factory setting: device ID 1, 19200 baud, RS-485 protocol “Binary” (UMB). Modbus is not on.
  • Switch with the UMB Config Tool (Windows, over the RS-485 line): choose Modbus RTU (or ASCII). The tool then preselects 19200 baud, even parity; 8E1, 8N1 and 8N2 at 19200 / 9600 / 4800 or lower are possible.
  • Address = UMB device ID (factory 1); IDs above 247 become 247.
  • Poll every 10 s or slower, as Lufft suggests: most values update at 10 s or slower anyway, and min / max / average are over the averaging interval you set (holding registers 2–6, 1–10 min).

Reg. No. or Reg. Addr.?

Lufft's table gives each value twice: a Reg. No. counted from 1 and a Reg. Addr. counted from 0. The address is what goes on the wire: wind speed (act.) is Reg. Addr. 42, Reg. No. 43, or 30043 in 3xxxx notation. Pick the wrong column and every value is its neighbour. Measurements are input registers (FC04); the few settings are holding registers (FC03 / FC06).

All values are 16-bit integers with a factor — no floats, no register pairs, no word-order question. Registers 51–70 hold the same values in US units (°F, mph, in), and further on are km/h, knots, absolute humidity and air density. The table is arranged so that one read of 0–50 gets everything a dashboard needs.

65535 Means Not There

The same map is used for every WS model. A value your model does not measure — or a sensor in error — reads 65535 (unsigned) or 32767 (signed). A WS501 has no precipitation sensor, so 25 and 48–50 read 65535: show it as “not fitted”, not as 655.35 mm/h. The absolute rain counter (48) wraps at 655.34 mm; use the difference register (49) for totals.

Common Mistakes

  • No answer at all: the sensor still speaks UMB binary — switch it with the UMB Config Tool.
  • Garbled frames after the switch: 8N1 set in the master; the tool preselects 8E1.
  • Every value is its neighbour: the Reg. No. column used instead of Reg. Addr.
  • Rain 655.35 mm/h or radiation 6553.5 W/m²: that sensor is not fitted on this model.
  • Temperature 6550 °C in winter: the signed register read as unsigned.
  • Temperatures in °F: the US block (51–70) read instead of the metric one.

Step-by-Step: Reading a Lufft WS with ModbusManager

  1. Switch the sensor to Modbus RTU with the UMB Config Tool and note the device ID.
  2. In ModbusManager choose RTU, 19200, even parity, 1 stop bit, that ID.
  3. Read FC04 from address 0, quantity 51, every 10 s.
  4. Apply the factors — or open the workspace below.

Frequently Asked Questions

How do I enable Modbus on a Lufft WS weather sensor?

The sensor ships with the UMB binary protocol. Switch it to Modbus RTU (or ASCII) with Lufft's UMB Config Tool over the RS-485 line; it then runs at 19200 baud, even parity, with the Modbus address equal to the UMB device ID.

Which address is wind speed on a Lufft WS sensor?

Input register address 42 (Reg. No. 43, 30043 in 3xxxx notation), wind speed act. in m/s x 10. Direction is at 18 in degrees x 10.

Why does my Lufft WS read 65535?

65535 (unsigned) or 32767 (signed) means the sensor is not fitted on this model or is in error. A WS501 has no precipitation sensor, so its rain registers read 65535.

Are Lufft WS Modbus values floats?

No. Every value is one 16-bit integer with a factor: temperature signed x 10, humidity, pressure, wind and radiation x 10, precipitation x 100.

How often should I poll a Lufft WS sensor?

Every 10 seconds or slower, as Lufft suggests. Most values update at that rate, and min, max and average are over the averaging interval set in the holding registers.
