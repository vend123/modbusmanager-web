CoolMasterNet VRF Modbus: Virtual Addresses, Unit ID 80 and the 16-Address Block

A CoolAutomation CoolMasterNet sits on the VRF bus of a Daikin, Mitsubishi Electric, Samsung, LG, Toshiba or other system and gives every indoor unit the same Modbus block: on/off, mode, fan speed, setpoint, room temperature and the malfunction code. One map for every brand — once you know how the Virtual Address turns into a register number, which is where most integrations go wrong by one.

Before Modbus Answers

  • Give the indoor units Virtual Addresses (VA). Nothing has a Modbus address until it has a VA. va auto assigns them all — and deletes the previous assignment, so the numbers can change; va + L1.102 0004 assigns one by hand. va lists them, for example L1.100 --> 0001 [Hex: 0x0011 | Dec: 00017].
  • Modbus TCP is off by default. modbus IP enable, then reboot. Port 502 (changeable with modbus server port). The server starts only once Ethernet has a link and an IP address.
  • Modbus RTU runs on a CoolMaster line set to line type L3 CG5: default 9600 8N1, slave address 0x50 = 80. line myid L3 51 changes the address — the value is hex. Every change needs a reboot.

Several RTU and TCP masters can be connected at the same time.

Virtual Address to Register

CoolAutomation gives the base of each indoor unit as VA × 16 + 1: VA1 = 17, VA2 = 33. Each unit has a 16-address block, and the same base applies to the holding, input, coil and discrete-input tables.

17 or 16? “17” reads as a 1-based register number. The Loxone integration guide that CoolAutomation hosts addresses the same register as 16 (“IO addresses will start at 16 for VA1”), and the workspace on this page uses 16 × VA on the wire. CoolAutomation's guidelines do not say which, so check on your gateway: read holding 16 and 17 for VA1 — the mode register holds 0–6, the fan register 0–5, and the setpoint two registers on is a number like 240.

The same quantity is in more than one table — on/off is holding +3 and coil +0, room temperature holding +6 and input +1. Pick one and stay with it.

Malfunction Codes

Holding +7 is 0 with no fault and 0xFFFF when the gateway has lost the indoor unit (discrete input +1 says the same). Any other value is the brand's own code, as a number to translate: on Daikin 0x11 = A1, 0x30 = E0, 0x40 = H0; Mitsubishi Electric codes read as four decimal digits; LG as two. For a display, the two ASCII input registers give the code as text.

Common Mistakes

  • No answer at all: unit id 1 instead of 80; Modbus IP not enabled (or not rebooted); no VAs assigned yet.
  • Every value one register off: the 17-versus-16 question above.
  • The map changed after adding units: va auto renumbered them. Assign VAs by hand on a finished installation.
  • Setpoint 240 °C: the × 10 not applied.
  • A mode that means something else: CoolMaster's 0 is Cool; Intesis gateways use 0 = Auto, 4 = Cool. A template from one gateway does not fit the other.
  • A fault code of 65535 treated as a brand code: it means the indoor unit is not talking to the gateway.

Frequently Asked Questions

What is the default Modbus address of a CoolMasterNet?

Slave address 80 (0x50) on RS-485, 9600 8N1. It is changed with line myid, and the value is given in hex. Modbus TCP uses port 502 and is off until you enable it and reboot.

How do I find the Modbus register of a VRF indoor unit on a CoolMasterNet?

Give the unit a Virtual Address (va command). Its 16-address block starts at VA × 16 + 1 in CoolAutomation's numbering, which is VA × 16 on the wire: VA1 mode is holding 16 (17 in 1-based tools). Check on your gateway which one yours answers.

What does malfunction code 65535 mean on a CoolMasterNet?

The gateway has lost communication with that indoor unit. 0 means no fault; any other value is the brand's own code (Daikin numbers translate to A1, E0, H0 and so on).

Why does the setpoint read 240?

Setpoint and room temperature are multiplied by 10: 240 is 24.0 °C.

Can I use an Intesis template on a CoolMasterNet?

No. The mode numbers differ (CoolMaster 0 = Cool, Intesis 0 = Auto and 4 = Cool), and so do the addresses. Each gateway has its own map.
