SunSpec Modbus for SMA, Fronius and SolarEdge

SMA, Fronius and SolarEdge inverters all speak SunSpec: one register layout, published by the SunSpec Alliance, in which every value travels with a scale factor and the data is organised in numbered models you find by walking a chain. Learn SunSpec once and you can read all three — provided you get each brand's own switch, unit ID and port right. This page covers the standard, the inverter model every one of them implements, and the brand-specific settings. Deye, Sunsynk or Growatt hybrid? See the hybrid inverter register map.

How a SunSpec Device Is Laid Out

  • Holding registers, function code 03.
  • The "SunS" marker. The map starts with the two registers 0x5375 0x6E53 — the ASCII text "SunS". The preferred location is protocol address 40000, which is register number 40001 in 1-based notation. SMA, Fronius and SolarEdge all say the same: request address 40000. The standard also allows 0 and 50000; a client tries 40000 first.
  • A chain of models. After the marker comes model 1 (the common model: manufacturer, model, serial). Each model starts with its ID and its length L (the number of registers that follow). The next model starts at address + 2 + L. The chain ends with ID 0xFFFF.
  • Walk the chain — do not hard-code addresses. The common model is 66 registers long in the specification, 65 on SolarEdge and Fronius; SMA inserts extra models before the inverter model; changing a Fronius setting moves everything after it. Reading the ID and L at each step tells you where the inverter model really is.
  • Up to 125 registers per request, big-endian, 32-bit values high word first.

Scale Factors

A SunSpec value is an integer with a scale factor (type sunssf, a signed 16-bit power of ten) beside it:

value = raw × 10SF      // raw 2071, SF -2  →  20.71

Read the value and its scale factor in the same request, and read the scale factor every time. Fronius states that its scale factors are not static: they can change with a firmware update and at runtime (auto-scaling). A program that caches the scale factor will one day be off by a factor of ten.

A point a device does not implement reads one of these — on a single-phase device, for example, phase B and C. Treat them as "no data", not as a reading.

The Inverter Model (103, Three-Phase, Integer + SF)

Models 101, 102 and 103 are the single-, split- and three-phase inverter models with integer values and scale factors; all three have length 50 and the same point layout. Float models (111–113)

Models 111, 112 and 113 carry the same quantities as float32 values with no scale factors (length 60). Fronius lets you choose between "float" and "int + SF"; switching it changes which model is present and shifts every model after it. In model 113, W is at offset 22 and WH at offset 32.

Brand Settings

SMA (Sunny Boy, Sunny Tripower, Sunny Highpower)

  • Modbus is off by default and a factory reset turns it off again. As Installer in the inverter's web interface: Device Parameters › External Communication › Modbus › TCP Server › Activated = Yes, port 502 (or through the installation assistant's network configuration).
  • Two unit IDs: SMA's own register profile answers on unit ID 3 by default; the SunSpec profile on unit ID + 123, i.e. 126. Asking SunSpec questions on unit 3 is the most common SMA mistake.
  • Which SunSpec profile you get depends on the country data set; the newer profile is dynamic, so models a device does not support are left out and addresses can differ between devices — walk the chain.
  • SMA's own profile has its own register lists, for example 30775 AC active power (S32, W) and 30529 total yield (U32, Wh). A missing value reads 0x80000000, typically at night.
  • SMA's guidance is not to poll more often than every 10 seconds.

Fronius (Symo GEN24, Primo GEN24, Datamanager)

  • GEN24: web interface › Communication › Modbus, enable the TCP server, choose the SunSpec model type (float or int + SF) and port (502 or 1502). The inverter answers on unit ID 1; smart meters start at an address offset of 200.
  • Datamanager (Symo, Primo, Eco): Settings › Modbus › Data output via Modbus = tcp, port 502. The inverter's unit ID is its inverter number; the smart meter is at 240.
  • Optional "inverter control via Modbus" and an IP restriction for control.
  • Allow time: Fronius asks for sequential queries and timeouts of at least 1 s (GEN24) or 10 s (Datamanager).

SolarEdge

  • Modbus TCP is off by default. On SetApp inverters: Commissioning › Site Communication › Modbus TCP › Enable — the default port is 1502. On older inverters with an LCD menu: Communication › LAN Conf › Modbus TCP, default port 502.
  • Unit (device) ID 1 on Ethernet.
  • One connection only. The inverter accepts a single Modbus TCP connection and drops an idle one after two minutes. A second program polling at the same time locks the first out.
  • Common model at 40000 (length 65), inverter model at 40069. Meters (models 201, 202, 203) follow the inverter model in the chain — their position depends on how many meters are configured, so walk the chain to find them.
  • RS485: device ID 1–247, baud rate settable from 9600 to 115200.

Power Limiting (Model 123)

Model 123 (immediate controls) carries WMaxLimPct (offset 5, a percentage of rated power), WMaxLim_Ena (offset 9) and OutPFSet (offset 10), with WMaxLimPct_SF at offset 23. Each brand gates writes differently (SMA without a Grid Guard code in the current profiles, Fronius only with "inverter control via Modbus" enabled).

Controls change how the plant runs. Export and power limits can be a condition of the grid connection. Agree changes with the installer, write only when a setpoint changes, and read it back.

Common Mistakes

  • Off by one: 40001 is the register number, 40000 the address to request.
  • Hard-coded addresses copied from another brand — or from the same brand with a different setting. Walk the chain.
  • Scale factor ignored or cached: values off by 10× or 100×, sometimes only after a firmware update.
  • SMA on unit 3: SunSpec is on 126.
  • SolarEdge on port 502: SetApp inverters default to 1502.
  • Second client: SolarEdge serves one connection; the second is refused.
  • Fronius float vs int + SF: reading model 103 offsets while the inverter presents model 113, or the reverse.
  • 0x8000 / 0xFFFF taken as data: those are "not implemented".

Step-by-Step: Reading a SunSpec Inverter with ModbusManager

1 Connect — Modbus TCP with the brand's port and unit ID above.

2 Find the inverter model — an FC03 window at 40000 shows the "SunS" marker and model 1's length; the inverter model starts at 40002 + 2 + L.

3 Poll the model in one request — e.g. 40069, quantity 52, so every value arrives together with its scale factor.

4 Apply the scale factors (Pro) — tag the raw value and its SF, and let a Structured Text line compute the result every cycle: AC_Power := W_raw * Math.pow(10, W_SF) / 1000;. Because the SF is read each time, the value stays right when the inverter changes it. A fixed Scale on a register tag is fine for devices with constant gains, but not for SunSpec.

Frequently Asked Questions

Is the SunSpec base address 40000 or 40001?

Both describe the same register: 40001 is the 1-based register number, 40000 the protocol address you put in the request. SMA, Fronius and SolarEdge all say to request 40000.

Why are my SunSpec values off by a factor of 10 or 100?

The scale factor was not applied, or was read once and cached. Every value is raw × 10SF, and the scale factor can change — read it in the same request as the value, every time.

Which unit ID does an SMA inverter use for SunSpec?

126 by default: SMA's own profile is on unit ID 3 and SunSpec on that ID plus 123.

Which port does SolarEdge use for Modbus TCP?

1502 by default on SetApp inverters, 502 on older inverters with an LCD menu. Modbus TCP is off until enabled, and only one connection is accepted at a time.

Where is the inverter model if the addresses differ from this table?

Walk the chain: read the ID and length at 40002, jump 2 + length, and repeat until you reach ID 101, 102, 103 (integer) or 111–113 (float). The offsets inside the model are the same on every brand.
