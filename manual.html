Getting started

ModbusManager is a Windows desktop tool for Modbus devices — PLCs, drives, energy meters, inverters and controllers. It polls and writes registers over Modbus TCP, RTU and ASCII, answers as a slave simulator, and in the Pro edition adds tags with Structured Text, a drag-and-drop HMI dashboard, a Historian, alarms, a gateway and Siemens S7 access. Everything runs locally; no cloud account is needed.

The main window

Toolbar

  • Connect / Disconnect opens the connection dialog (F3).
  • The amber badge names the selected poll window. FC, address, Base 0 / Base 1, Quantity, Slave ID and Interval belong to that window. Delay is a global pause between successive requests.
  • ▶ Start / ■ Stop starts and stops polling; + Window adds a poll window (Ctrl+M).
  • Display: Swap, Float, Big-endian / Little-endian change how 32-bit values are shown in the table.
  • The moon/sun button switches the dark and light theme; the flag selects the language.
  • Workspace (save) and the folder button (open), Templates Pro, Print, and License, which also shows the licence state: “Trial: 12d”, “✓ License” or “License expired”.
  • On the right: the connection state and the Auto-reconnect switch.

Poll windows

Each poll window is one block of registers (function code, start, quantity, slave ID, interval). Every enabled window is polled in the background, whichever one is selected — so one meter's voltages and another device's status can be read side by side. In the list each window has pause/resume, edit (✎), save to the Saved list, and remove (✕).

Tabs

Registers, Chart, Write, Serial Monitor, Test Center, Slave Scan, Address Scan, Slave Std + Pro · Dashboard, Tags, History, Alarms, Gateway Pro.

Log, status bar, tray

The TX/RX log under the tabs shows every request and reply (Stop pauses it, Clear empties it). The status bar counts TX, RX and Errors, shows the Latency and the device address, and has the 🔍 Diagnose link Pro. The tray icon menu offers Keep running when window is closed and Start with Windows — used by the gateway and alarms when they must run without a window. Help → User manual opens this page.

Modbus TCP

  1. Press Connect, stay on TCP/IP.
  2. Enter the IP address and port (usually 502) and press Connect.
  3. Set the Slave ID (unit ID) of the poll window — often 1, sometimes 0 or 255 for a direct TCP device; a gateway uses the ID of the serial device behind it.

Modbus RTU

  1. Plug in the USB-RS485 adapter and open Connect → RTU. Pick the Serial port (↻ refreshes the list).
  2. Match the device: Baud rate (1200–115200, default 19200), Parity, Data bits, Stop bits. Custom baud overrides the list.
  3. RTS Toggle raises RTS while sending, for RS-485 adapters that switch direction on RTS. Leave it off for adapters with automatic direction control (most USB adapters).
  4. Remove Echo is for adapters that echo what they send: the echo of the request is dropped before the reply. Leave it off otherwise — on an adapter without echo, single writes (FC05/FC06), whose reply equals the request, would time out.

Modbus/TCP Security (TCP-SEC)

  1. Open Connect → TCP-SEC, enter the IP address and port (802).
  2. Client certificate and Private key: the PEM files the device trusts (issued by the device’s or your own certificate authority). Choose… loads a file once; it is kept in the application’s data folder, not in the dialog.
  3. CA certificate: the certificate that signed the device’s certificate. With Verify device certificate ticked, a device whose certificate it did not sign is refused — untick it only for a test device with a self-signed certificate.
  4. Connect. The log names the TLS version; a refusal says why (untrusted device, wrong name, expired, or the device rejected the client certificate).
Note — auto-reconnect

With Auto-reconnect ticked, a dropped connection is retried up to 10 times with growing pauses (2 s up to 15 s); the log shows “Auto-reconnect attempt n/10”.

Tip

Unknown baud rate or slave ID? Use Auto-detect Pro in the Slave Scan tab.

  • New poll window (+ Window or Ctrl+M): Name, Function, Start address, Quantity (max 125), Slave ID, Interval (ms). In Pro, ↑ Import CSV loads a register map with descriptions.
  • Base 0 / Base 1: Base 0 is protocol addressing (first register = 0), Base 1 documentation addressing (first register = 1). Choose what your device manual uses. A “40001”-style manual usually means Base 1 with FC03.
  • Interval is per window; Delay is a global gap between requests, useful for slow serial devices.

The register table

Every value is shown at once as Decimal, Hex, Binary, ASCII, 32-bit signed/unsigned, 64-bit signed/unsigned and 64-bit float, plus a Description. A value that changed since the last poll is marked ▲.

  • Double-click a value to write it (FC06/FC05/FC16) — see Writing. Double-click the description to name the register.
  • Right-click: Copy value, Write value, Value Names (show 0 as “Off”, 1 as “Run”…), Conditional Colors (colour a cell by a rule). On a 32-bit cell, right-click picks the word order: big-endian, word-swapped, byte-swapped or fully reversed.
  • Row buttons: 📊 Add to Dashboard and 📈 Log to History Pro.
  • Filter… narrows the rows; ⬇ Export CSV saves the active window or all windows.
  • Pro Snapshot stores a baseline and highlights what changed since (Clear diff ends it); PDF report prints a Modbus commissioning report of the windows.
Scaling

In Pro the register table always shows the raw value the device sent. Engineering units belong to tags (Scale and Offset) and to History series, so one register can be scaled once and used everywhere. In Standard, right-click → Scaling multiplies and offsets the value in the table.

Writing values Std + Pro

The Write tab sends any write function: FC05 single coil, FC06 single register, FC16 multiple registers, FC22 mask write and FC23 read/write multiple. Choose the Format (16-bit, 32-bit signed/unsigned/float, 64-bit signed/unsigned/float) and the tool splits the value into registers in the word order you selected. Enter the register address, value (or comma-separated values) and slave ID, then Send command →. The reply or the exception is reported at once.

For a quick change, double-click a value in the register table: the Write Register dialog opens with the address filled in.

Warning

A write changes the controller. Check the slave ID, the address base and the value before sending — especially on running machinery.

Chart, Serial Monitor & Test Center Std + Pro

  • Chart: up to three charts, each one register with its slave, format, name and Y range. Cursor reads values off the line, and Log records the series to a file you can download.
  • Serial Monitor: the raw bytes on the connection, as HEX or ASCII with timestamps; Download saves the capture.
  • Test Center: compose one request by hand — FC01–06, 15, 16, 22, 23, 08 (diagnostics, with sub-codes), 11 (comm event counter), 17 (report server ID) and 43/14 (device identification) — and inspect the exact reply. A history keeps the last requests.

Scanning & diagnostics

Slave Scan Std + Pro probes a range of slave IDs (From ID / To ID) with one read and lists who answers — for a device on the bus whose address is unknown. Address Scan sweeps a register range on one slave in blocks and lists which addresses return data — for mapping an undocumented device; the result exports to CSV.

⚡ Auto-detect Pro, in the Slave Scan tab, tries baud rates, parity settings and slave IDs on a COM port (or unit IDs behind a TCP gateway) until a device answers, then Use these settings applies them.

🔍 Diagnose Pro, in the status bar, reads the recent error history and says what kind of failure it is: no reply, timeouts now and then, a Modbus exception, refused or reset TCP, garbled frames, port not found or port busy — with what to check for each.

Slave simulator Std + Pro

The Slave tab makes ModbusManager a Modbus server that answers like real hardware: for testing a SCADA, HMI or PLC program before the device exists, for training, or as the far end of the gateway.

  1. + under Slave devices adds a block: Slave ID, Register type (Holding, Input, Coils, Discrete Inputs), Start address, Quantity (up to 1000). A slave ID can have several blocks; overlapping blocks are refused.
  2. Under Server start TCP on a port (502 by default) and/or RTU on a COM port. The RTU line has its own baud, data bits, parity and stop bits — independent of the Connect dialog, so the same PC can be master on one port and slave on another.
  3. Type a value straight into the Decimal column, or press the ⚙ button for a simulation.

Simulation types: Static value Pro, Counter ↑, Counter ↓, Sine wave, Random, Ramp and PID loop (simulated process), each as UInt16, Int16, Int32, UInt32 or Float32 with a word order. Keep the simulation interval well below the master's poll interval, and a sine period at least ten times the poll interval, or the master sees repeated or skipped values.

The PID loop uses six holding registers: +0 process value ×10, +1 setpoint ×10, +2 output 0–1000, +3 mode (1 = auto), +4 P ×10, +5 I in seconds. A master — or the dashboard's PID faceplate — can change the setpoint and watch the process follow.

Link panel

The Link line tells you whether a master is really there: “TCP :502 — master 192.168.0.10, connected … requests · last 0.7 s ago”, the RTU request rate and bad-CRC frames (wrong baud or parity), requests for a unit ID this slave does not have, and refused requests with the reason in the Request log below.

Tags & Structured Text Pro

A tag gives a value a name, so dashboards, alarms, the Historian, the gateway and scripts can use WellLevel instead of “slave 1, FC03, address 0”.

TypeDescription
Register (REG)A Modbus value: Slave ID, Reg Type, Address, Data type (Int16, UInt16, Int32, UInt32, Float32), Word order (High word first / Low word first), Scale × and Offset +.
Internal (INT)A value that lives in the application, usually set by a script.
Siemens S7 (S7) betaA value in an S7 PLC: PLC, area (DB, M, I, Q), DB number, byte, bit and type. See Siemens S7.

Scale and offset: value = raw × scale + offset. A write to a scaled tag (from the dashboard, a script or the gateway) is converted back to the raw register value. Names start with a letter and contain letters, digits and _; they are not case-sensitive in scripts. Renaming a tag carries its dashboard bindings, alarms and history with it; deleting one tells you first where it is used.

Note — where values come from

A register tag gets its value from polling: its address must be inside a running poll window or bound to a dashboard element, and polling (▶ Start) must run.

Structured Text

The Script Editor (Structured Text) runs IEC 61131-3 style code against the tags. ▶ Run once tests it; ▶ Start loop runs it every Loop interval (minimum 100 ms). The output box shows each assignment or the error with its line number. A run is stopped after 2 s, and the loop stops after five errors in a row.

(* specific energy of the pump and an overflow flag *)
IF Flow > 0 THEN
  SpecificEnergy := PumpPower / Flow;
ELSE
  SpecificEnergy := 0;
END_IF;

Overflowing := Inflow > Flow AND WellLevel > 80;

Supported: :=, + - * /, comparisons = <> < > <= >=, AND OR NOT, TRUE FALSE, IF … ELSIF … ELSE … END_IF, FOR i := 1 TO n DO … END_FOR and comments (* *). WHILE, REPEAT, CASE and the standard function blocks (timers, LIMIT…) are not available.

HMI dashboard Pro

The Dashboard is a drag-and-drop canvas for operator screens. Pick an element from the palette, place it, bind it to a register, tag or S7 address in the Properties panel, then press ▶ Runtime to operate it.

Pages and toolbar

  • Pages: + adds one; double-click a tab for Page settings — name, size, and Popup page (hidden from the tabs, opened by clicking an element whose Open popup points to it). The tab’s × deletes a page after asking; Ctrl+Z brings it back.
  • Undo / Redo (Ctrl+Z / Ctrl+Y), Copy / Paste (Ctrl+C / V), snap to grid, background colour.
  • Theme: Classic (flat) or Modern (cards, 3D equipment, glow). The theme changes only the look — no binding or setting of any element changes. In Modern, ✨ switches the glow and moving-value effects.
  • 📷 exports the page as PNG; 📦 makes a Runtime package; ⛶ goes full screen (Esc leaves).
  • Drag a frame to select several elements; arrow keys nudge; the Actions group aligns, locks, deletes and clears the page.

Properties and binding

Select an element to open Properties. Source is Register (slave ID, register type, address — polled in the background while polling runs, even without a poll window), Tag, or Siemens S7 (beta). The other fields follow the element: label, min/max, unit, decimals, font size, compare and threshold, on/off colours and labels, states (0=Off:#8892a4,1=On:#00d4aa), options for Enum Write, write value for a Button, flow and spin direction, image file, size, layer order. In the Modern theme a Style (Modern) block adds main and second colour, alarm and warning levels, arc span, glow and glass card. A KPI Card shows the change over a period, in per cent or in units.

Trends and channel charts

  • Trend: one value over time. Max points sets the length, Sample interval (ms) how often a point is taken (default 1000 ms; never faster than the value actually arrives). A steady value keeps drawing.
  • Bar Graph, Value Table, Multi Trend, Alarm List hold several channels: 📋 Edit channels… sets each channel’s source (register or tag), name, unit, colour and, for Multi Trend and Value Table, Visible when (show the channel only while a tag is non-zero).
  • Multi Trend adds max points, sample interval, Scroll back (min) up to 24 h, decimals, Y range and legend position. In Runtime it has pause, zoom on X and Y, a time-window dialog and a scroll-back slider.
  • Alarm List uses manual thresholds or the alarm system; with the alarm system it, and the Alarm Banner, offer ✓ Ack all.

PID Loop faceplate

The PID Loop element shows a controller: PV, setpoint, output bar, a small trend, auto/manual and the P, I and D values. Each role — Process value, Setpoint, Output, Auto/Manual, Manual output, P, I, D — is bound to a register or a tag, with a raw-divisor for PV/SP and for the output (e.g. 10 when the register holds ×10). In Runtime the operator can change the setpoint, switch auto/manual and set the manual output, each after a confirmation. P, I and D are only displayed.

Runtime mode and writes

  • Write elements (Button, Toggle, Slider, Setpoint, Enum Write, PID) write only in Runtime, and only after the element has read a value, so a click in edit mode or on an empty screen never sends anything.
  • A value that stops arriving is dimmed and keeps its last reading; hover shows “Not current — last update …”. Text in a numeric field shows “—”.

History (Historian) Pro

The Historian stores values in a local database for days or months and charts any time range.

  • Start logging: 📈 on a register row or a tag, or + Add in Logged Series (name, register or tag, slave, function, address, data type, word order, unit). Recording starts at once.
  • Samples arrive at the poll rate. Deadband stores a sample only when the value moved at least that much (0 = store all); writes to disk are batched every 5 s.
  • Scale × and ⚙ Display scale (scale, offset, decimals, chart min/max) change how a series is shown; the database keeps the raw value, so a scale can be corrected later.
  • Time range: 1h, 24h, 7d, All, or From/To. Drag on the chart to zoom, Manual scale fixes the Y axis, Min/max lines marks the extremes; the statistics show points, min, max and average.
  • Data management: database size, ⬇ Export CSV of the selected series (ISO time, milliseconds, value), and Delete data older than 1 day … 1 year or a date. Series definitions are kept.

Alarms Pro

  • + New alarm: name, description, source (register or tag) and condition: greater, less, greater or equal, less or equal, equal, not equal, between, outside range.
  • Greater/less conditions have two optional levels, ⚠ Warning limit and ⛔ Critical limit; equal/not equal take a value; range conditions take lower and upper.
  • Hysteresis keeps a value that hovers at the limit from raising and clearing the alarm repeatedly; Delay (s) raises it only after the condition has held that long.
  • Active alarms lists what is raised; ✓ Ack acknowledges. Sound on / Muted and Repeat until ack / Beep once choose the alert. History lists raised, cleared and acknowledged times.
  • On a dashboard, the Alarm Banner and an Alarm List in alarm-system mode show the same alarms and acknowledge them.
Note

Alarms are evaluated by the application while it runs — keep it running in the tray (Keep running when window is closed) for unattended monitoring. There are no e-mail or SMS notifications.

Gateway Pro

The gateway polls several devices as a master and republishes the values you choose as one common Modbus TCP map — or as a data block an S7 PLC reads with GET — with type and scale conversion both ways. Writes from the PLC are forwarded to the device.

  1. PLC side: the Slave TCP port the PLC or SCADA connects to (502 by default).
  2. Source endpoints: + TCP (host, port), + RTU (COM port, baud, parity), + Siemens S7 (beta) (a PLC from the S7 list) and + Tags (this application’s tags, including script results).
  3. Mapping rows: name, endpoint, mode (read device → map, or write map → device), source slave ID, type and address (an S7 address or a tag for those endpoints), data type, scale and offset, then the destination: Modbus map (common slave ID, type, address, data type) or S7 DB (beta) (DB, byte, bit, S7 type).
  4. Start gateway. Each endpoint and row shows its state; a row with an error says why.

⬆ Import CSV and ⬇ Export CSV move rows and endpoints to and from a spreadsheet. Start gateway automatically plus the tray options Keep running when window is closed and Start with Windows run it unattended. The gateway configuration is saved with the workspace.

S7 server: the PLC reads a DB from ModbusManager beta

With Serve the rows whose Dest is “S7 DB” to Siemens PLCs the gateway also answers as an S7 server (port 102): an S7-1200/1500 reads the rows with a GET block and writes them with PUT — no Modbus program in the PLC. In TIA Portal create a GET/PUT connection to an unspecified partner at this PC’s IP address and use absolute addresses such as P#DB100.DBX0.0 BYTE 16. A DB is as long as its rows reach, in steps of 16 bytes; a PUT is forwarded to the row’s source when its value changes.

Allowed PLC addresses

Only PLCs listed in Allowed PLC addresses (comma-separated IPs) can connect. An empty list refuses everyone, and the panel warns about it. The list applies at once; removing an address drops that PLC.

Siemens S7 (beta) Pro

Pro reads and writes Siemens S7-1200, S7-1500 and S7-300/400 PLCs over S7 communication (PUT/GET) — data blocks, merkers, inputs and outputs — with no communication block in the PLC program. It is released as beta: tested against a simulated S7 PLC; feedback from real CPUs is welcome.

  1. In TIA Portal: CPU properties → Protection & Security → Permit access with PUT/GET communication; for every DB you read, turn off Optimized block access; download.
  2. In ModbusManager: Tags → Siemens S7 (beta)… (also in the gateway, the dashboard source and the Runtime service menu) → + Add PLC: ID, name, IP address, port 102, rack 0 and slot 1 for S7-1200/1500 (slot 2 for S7-300/400), poll interval. Test read checks an address.
  3. Create S7 tags, bind dashboard elements to Siemens S7, or add an S7 endpoint to the gateway.

Address syntax: DB1,REAL4 · DB1,INT2 · DB1,X12.0 (bit) · MW2 · M0.0 · IW64. Writes are converted to the address type (a bit takes 0/1, integers are rounded, REAL keeps decimals). The PLC’s state shows as online, connecting, error, or idle when nothing reads from it. The PLC ID ties tags to the PLC, so a runtime package keeps working when each machine’s PLC has a different IP.

FAQ

How do I connect to a Modbus TCP device?+
Press Connect, stay on TCP/IP, enter the IP address and port (502 by default) and connect; then set the slave/unit ID in the poll window and press Start.
Which function codes are supported?+
Reading: FC01, FC02, FC03, FC04. Writing: FC05, FC06, FC15, FC16, FC22 and FC23. The Test Center also sends FC08 diagnostics, FC11, FC17 and FC43/14 device identification.
What is the difference between address base 0 and base 1?+
Base 0 uses protocol addresses (first register = 0); Base 1 uses documentation addresses (first register = 1). Pick the one your device manual uses.
Can I test without hardware?+
Yes. The Slave tab simulates one or more devices over TCP or RTU, with counters, sine waves, ramps, random values and a simulated PID process.
What is the difference between Standard and Pro?+
Standard ($49) is the master/slave test tool. Pro ($119) adds the HMI dashboard, tags and Structured Text, Historian, alarms, gateway, Siemens S7 and Runtime packages.
Is there a free trial?+
Yes, 14 days with every feature and no credit card. After that you activate a key issued for your machine.
Windows shows “Windows protected your PC” when I run the installer — is that a problem?+
No. The installer is code-signed, but SmartScreen shows this notice for releases it has not seen many times yet. Click More info, then Run anyway. Every release is published on our GitHub releases page, so you can check the download comes from the official source.
